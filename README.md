# TechDish Portfolio Website

A clean, responsive **portfolio website** built with **HTML5** and **CSS3**.
Showcase your **skills, projects, resume, and contact details** in one place.

---

## 🚀 About

This project is a lightweight, beginner-friendly portfolio template.
It is easy to customize and deploy for students and developers.

---

## ✨ Features

* Simple, responsive design (works on mobile & desktop)
* Sections: Home, About, Projects, Skills, Contact
* Easy to modify colors, fonts, and layout
* Works with GitHub Pages, Netlify, or Vercel

---

## 🛠️ Tech Stack

* HTML5
* CSS3 (Flexbox + Grid)
* (Optional) Small JS for smooth scroll or menu toggle

---

## 💻 How to Run Locally

1. Clone the repo:

```bash
git clone https://github.com/<your-username>/portfolio-techdish.git
cd portfolio-techdish
```

2. Open `index.html` in a browser:

* Double-click the file, or
* Run a local server:

```bash
python -m http.server 8000
```

and visit `http://localhost:8000`

---

## 📦 Deployment (GitHub Pages)

1. Push to GitHub.
2. Go to **Settings → Pages**.
3. Select branch `main` and root (`/`).
4. Save → Site will be live at:
   `https://<your-username>.github.io/portfolio-techdish/`

---

## ✍️ Customization

* Update `index.html` with your **name, bio, and project details**.
* Edit `css/styles.css` to change **colors, fonts, and layout**.
* Add your resume (PDF link).

---

## ✅ Best Practices

* Keep project descriptions short & link to demos/GitHub repos.
* Use semantic HTML for better SEO & accessibility.
* Test on different devices (desktop + mobile).
